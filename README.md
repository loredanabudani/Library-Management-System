# Library Management System

A Java console-based library management system built using Object-Oriented Programming (OOP) and ArrayList.

## Features

- Add a new book
- Display all books
- Search for a book by title
- Delete a book
- Find the book with the most pages
- Calculate the average number of pages
- Edit book information
- Exit the program

## Technologies Used

- Java
- ArrayList
- Object-Oriented Programming (OOP)

## OOP Concepts

This project demonstrates:

- Classes and Objects
- Constructors
- Encapsulation
- Getters and Setters
- Methods
- ArrayList
- Loops and Conditional Statements
- Searching and Filtering

## How to Run

1. Clone or download the repository.
2. Open the project in a Java IDE such as Eclipse.
3. Run `LibraryManagementSystem.java`.
4. Use the console menu to manage the books.
